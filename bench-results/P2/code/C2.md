# C2: profile output shows fusion

Date: 2026-11-04

## Test

`EsqlActionIT.testProfileShowsFusedEval`

- Query: `FROM fusion-profile-idx | EVAL v = (a + b) * c | STATS SUM(v)`
- `profile(true)`, two runs (production `min_sightings` default 2)
- Assert some `OperatorStatus.operator()` contains `Fused[`
- `esql.fusion.enabled=false` via `updateClusterSettings`; assert no operator string contains `Fused[`
- Also asserts `SUM(v)=20` and feature-flag assume

IT: `./gradlew :x-pack:plugin:esql:internalClusterTest --tests org.elasticsearch.xpack.esql.action.EsqlActionIT.testProfileShowsFusedEval` exit 0 (1 test, 6.5s). Log: `C2-profile-it.log`.

## Example strings

Fused Eval operator (profile `operator` field, from `EvalOperator.toString()` + `FusedExpressionEvaluatorFactory.toString()`):

```
EvalOperator[evaluator=Fused[shape=<shape>, strategy=<vectorStrategy>, unfused=<unfused factory tree>]]
```

`Fused[` is the substring the test pins. Nested fused factories use the same prefix.

Unfused (kill switch off): same slot is an ordinary generated-evaluator tree, e.g. `MulLongsEvaluator[...]` wrapping `AddLongsEvaluator[...]`. No `Fused[` in any operator string.
